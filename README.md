
# IoT Home Automation - 2 Light Control

Arduino UNO based home automation system to control 2 lights.

### 🔧 Components Used
- Arduino UNO
- 2 LEDs (as Light 1 & Light 2)
- 2 Resistors (220 ohm)
- Wokwi Simulator

### ⚡ Circuit Connection
- Light 1 -> Pin 13
- Light 2 -> Pin 12
- GND -> Common

### 💻 How it Works
- Send `1` in Serial Monitor -> Light 1 ON
- Send `0` -> Light 1 OFF
- Send `2` -> Light 2 ON
- Send `3` -> Light 2 OFF

### 📁 Files in this Repo
- `sketch.ino` - Arduino code
- `demo.mp4` - Working video from Wokwi
